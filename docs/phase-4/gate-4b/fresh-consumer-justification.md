## Governing criterion

WS1 §1.13 defines a fresh Consumer for a particular proving run as one that lacks material prior Project-specific, task-relevant knowledge that could compensate for a deficient Context Package. The Gate 4B criterion is whether the governed package—not hidden historical knowledge—gives a downstream consumer a reliable basis to understand the validated scope, qualifications, adverse history, authority, and later proving boundary. Actual freshness remains an exact-run, evidence-based preflight question and is not performed here.
