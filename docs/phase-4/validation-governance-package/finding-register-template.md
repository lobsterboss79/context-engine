# Finding Register Template

**Template status:** No fictional finding is recorded. Finding discovery is not remediation authority.

| Field | Record value |
| --- | --- |
| Finding ID | `F-[stable ID]` |
| Linked evidence/result | `[Evidence IDs and result state]` |
| Concise finding | `[future statement]` |
| Severity | `[BLOCKER / MATERIAL / MINOR / OBSERVATION]` |
| Primary finding type | `[IMPLEMENTATION / INTEGRATION / SECURITY/GOVERNANCE / OPERATIONAL / DESIGN / PROVING-PROTOCOL / CONSUMER-USABILITY]` |
| Secondary type(s) | `[only where genuinely necessary]` |
| Owner/investigator | `[identity/role]` |
| Cause analysis | `[evidence-based; not disposition]` |
| Status/lifecycle | `[OPEN -> UNDER REVIEW -> DISPOSITIONED -> REMEDIATION AUTHORIZED -> RETEST PENDING -> CLOSED, as applicable]` |
| Governed disposition | `[NO CHANGE REQUIRED / REMEDIATION AUTHORIZED / DESIGN/GOVERNANCE REVIEW REQUIRED / PROTOCOL/RUN INVALID — DISCARD/RESTART / ACCEPTED LIMITATION / FUTURE-WORK CANDIDATE / DUPLICATE/SUPERSEDED]` |
| Disposition authority | `[authority/date/decision record]` |
| Remediation authorization | `[linked authorization or none]` |
| Remediation/retest evidence | `[future IDs]` |
| Residual limitation | `[future statement or none]` |
| Closure evidence | `[future evidence and rationale]` |
| Lineage/related findings | `[superseded/duplicate/related IDs]` |

Severity, type, result state, and disposition are independent. H3 controls actual impact. BLOCKER stops the affected activity; MATERIAL or genuine ambiguity requires Project Owner disposition. Closure requires governed disposition and evidence.
