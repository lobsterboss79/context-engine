## Scope, exclusions, and methodology

Phase 4 is the future governed-evidence phase for determining what v0.1 demonstrably supports through controlled integrated validation, then only after the applicable gate and authorization, fresh-Consumer proving. Implementation testing is an evidence input; it does not establish integrated validation. Validation establishes controlled integrated behavior against approved semantics. Proving establishes whether a validated system supports a real task for a genuinely fresh Consumer under the frozen proving protocol. Neither validation nor proving establishes production readiness.

The governing scope, exclusions, non-negotiable invariants, and execution dependencies are unchanged from the [Phase 4 checklist](../../../checklists/checklist-phase-4-validation-integration.md#purpose-authority-and-phase-boundary).
