## Deferral basis

The frozen package payload is 61,592 UTF-8 bytes and is immutable at the successor-004 execution-control boundary.  The approved disposable synthetic test established that normal Firefox/Wayland paste into the tested ChatGPT Temporary Chat interface converted long text into a `Pasted text` attachment.  The tested UI did not expose the approved anticipated direct-text recovery option.  No message was submitted, no frozen proving material was disclosed, and the reserved Consumers remained untouched.

The evidence establishes that direct-text composer feasibility is blocked in the tested configuration; it does not establish exact frozen-payload submission feasibility.  The attachment-delivery assessment concludes that attachment delivery is not viable under the current successor-004 controls: it would materially change the package/control experiment and require new governance.  No successor-005 is authorized.

- active-corpus, provenance, authority/currentness, limitation/uncertainty, disclosure, and artifact-integrity validation; and
- the frozen successor-004 package and control payload integrity evidence.

This decision does **not** establish external Consumer usefulness, Consumer improvement, package-arm/control-arm comparison, fair-control outcome, task-performance outcome, or any Gate 4C proving result.
